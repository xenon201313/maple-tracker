판매가에서 구입비와 수수료를 빼야 손익입니다

1억 메소에 구입한 물건을 1억 2,000만 메소에 판매하고 판매 수수료가 3%인 가상 사례입니다. 판매가 전체를 순수익으로 계산하지 않습니다.

항목계산메소
구입 지출실제로 지급한 금액100,000,000
판매가거래한 물건의 전체 금액120,000,000
판매 수수료120,000,000 × 3%3,600,000
실제 수령액120,000,000 − 3,600,000116,400,000
손익116,400,000 − 100,000,00016,400,000

실제 손익 = 판매 후 수령액 − 구입비 = 1,640만 메소

아직 판매하지 않았다면 예상 가격은 비교에만 사용합니다. 이 경우 이미 쓴 구입비 1억 메소는 지출이지만 판매 수입은 0이며, 보유 중인 물건의 예상 가격을 순수익으로 더하지 않습니다.

공개 손익 계산기에서 같은 구입비·판매가·수수료를 넣고 ‘실제로 판매 완료’를 끄면 차이를 확인할 수 있습니다. 파티 드랍은 내 몫과 송금 수수료·분배 조건까지 확인해야 하므로 파티 분배 계산 사례를 함께 보세요.

획득 기록과 판매·분배 기록을 구분합니다

10월 28일에 얻은 드랍을 11월 2일에 팔았다면 획득 사실은 10월 기록이고 실제 판매는 11월 거래입니다. 미정산함에서는 획득일, 판매일, 판매 수량과 파티 지급 상태를 나누어 확인합니다. 일부만 팔았다면 남은 수량을 유지합니다.

원래 보스·손익 화면에 이미 수익을 반영한 거래를 미정산함으로 가져왔다고 같은 금액을 기존 통계에 다시 더하지 않습니다. 미정산함은 연결한 원본과 정산 과정을 확인하는 별도 기록입니다. 획득 기준 합계와 판매일 기준 금액을 비교할 때는 각 화면의 기준을 먼저 확인하세요.

솔 에르다 조각도 보유 수량과 판매 수익을 구분합니다. 이미 메소로 환산한 조각을 다시 판매 정산에 넣기 전에는 조각 중복 반영 예제를 확인하세요.

가져온 강화 이력은 금액을 확인한 뒤 확정합니다

넥슨 API는 강화 시도와 결과를 제공하지만, 모든 구입비나 실제 메소 차감액을 그대로 알려 주지는 않습니다. 장비 레벨·단계·할인 조건으로 계산한 비용은 추정치로 확인합니다. 무료 획득 큐브나 보유 명성치를 사용했다는 이유로 새로운 메소 지출을 만들지 않습니다.

지출 기록에서 최종 금액을 확인해 지출 반영한 내역만 기존 지출 합계에 포함합니다. 같은 비용을 이미 수기로 기록했다면 API 이력을 다시 확정하지 마세요. 장비 투자 장부에 이 내역을 연결하는 것은 비용을 모아 보는 작업이며 지출을 한 번 더 생성하는 작업이 아닙니다.

장비 상태나 전투력이 함께 달라졌더라도 그 차이가 한 번의 강화만으로 발생했다고 단정하지 않습니다. 버프, 장비 프리셋, 다른 장비 변경과 API 반영 시점도 달라질 수 있습니다.

자산·성장 계획의 여섯 기능을 읽는 방법

API 연결 없이 직접 입력으로도 사용할 수 있습니다. API는 반복 입력을 돕고, 거래 금액·계획·소요 시간은 사용자가 확인합니다. 새 계획을 만든 것만으로 기존 수익·지출 합계가 바뀌지는 않습니다.

장비 투자

장비를 정하고 구입비와 기존 확정 지출을 연결합니다. 예산과 실제 연결 비용을 비교하되, API 추정 비용과 프로젝트 메모를 확정 지출로 자동 전환하지 않습니다. 같은 이름의 다른 장비를 연결하지 않았는지도 확인하세요.

미정산함

획득한 물건, 일부 판매와 판매 완료, 파티 분배 상태를 정리합니다. 실제 판매일·수량·금액·수수료를 확인하며, 기존 원본에 반영한 수익과 중복 집계하지 않습니다.

자금 계획

시작일과 시작 잔액을 직접 정하고 이후 기록으로 장부 기준 잔액을 봅니다. 목표별 배정액과 남길 준비금을 분리합니다. 내 캐릭터 사이의 메소 이동은 계정 전체에 새로 생긴 수익이 아닙니다.

재획 비교

사냥터·실제 사냥 분·버프·소모품 비용을 회차와 연결해 시간당 메소와 조각을 비교합니다. API의 하루 경험치에는 다른 콘텐츠도 섞이므로, 회차 경험치는 직접 확인한 값으로 구분합니다. 미판매 조각 가치는 예상값으로 봅니다.

보스 계획

가능한 보스와 평균 소요 시간을 직접 정하고 남은 시간 안의 조합을 검토합니다. 완료 상태는 기존 보스 기록을 참고합니다. 결정석 예상 내 몫과 실제 판매 수익은 구분하며, 드랍을 확정 수입으로 보장하지 않습니다.

심볼 예산

현재 심볼과 목표, 앞으로 쓸 메소와 예정일을 정리합니다. API가 미래 비용을 반환하는 것은 아니므로 사용한 비용표의 기준이나 직접 확인한 금액을 남깁니다. 예정액은 실제 지출과 별도로 확인합니다.

재획·잔액레벨·경험치 등 캐릭터 정보사냥 시간·장소·수입, 실제 판매, 시작 잔액과 외부 거래

현재 공식 메이플스토리 API에는 본인의 경매장 판매 내역과 보유 메소 잔액 조회가 없습니다. 자금 계획의 잔액은 게임과 직접 동기화한 값이 아닌 입력한 기록 기준 잔액입니다. 기록하지 않은 외부 거래가 있다면 실제 보유 메소와 차이가 날 수 있습니다.

API는 항목별 갱신 조건과 조회 가능 기간이 다릅니다. 스케줄러는 조회 시점 기준 최근 14일의 정보를 제공하므로 과거 누락을 무제한 복구하는 자료로 취급하지 않습니다. 응답이 늦거나 없을 때는 마지막 조회 상태를 확인하고 기존 기록을 빈 값으로 바꾸지 않도록 주의하세요.

기간이 바뀌어도 과거 기록은 남깁니다

일간·주간·월간 기록은 각 기간을 선택해 확인합니다. 신규 기간을 열거나 입력 상품이 종료된 것은 이전 기록을 삭제한다는 뜻이 아닙니다. 사용한 단가·수수료와 확정 지출을 보존하고 현재의 가격을 과거 거래에 일괄 적용하지 않습니다.

큰 수정과 기기 이동 전에는 JSON 백업을 보관하세요. 넥슨 계정의 장부와 브라우저의 기록이 다르면 사용할 장부를 먼저 확인합니다. 복구 기능을 사용할 때에도 현재 상태를 먼저 백업하고, 개인 장부 전체나 인증정보를 공개 제보에 올리지 마세요.

API 조회 정보와 사용자가 직접 적은 거래·메모는 서로 다른 자료입니다. API 캐시는 제공 정책에 맞춰 갱신하고, 사용자 확정 기록은 별도로 보존하는 기준으로 관리합니다. 장부에 저장된 추정·확정 여부와 기록 시점을 함께 읽어 주세요.
