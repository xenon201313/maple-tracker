# 나만의 메계부

메이플스토리 플레이어를 위한 개인 수익 기록장입니다. 재획, 솔 에르다 조각, 일간·주간·월간 보스 결정석, 드랍 아이템, 손익 기록을 한곳에서 관리하고 통계로 확인할 수 있습니다.

- 서비스: [maple-trackers.com](https://maple-trackers.com)
- 저장소: [xenon201313/maple-tracker](https://github.com/xenon201313/maple-tracker)

## 운영 웹 배포

2026-10-06부터 운영 화면은 `maple-tracker-web` Cloudflare Worker에서 제공합니다. **GitHub main에 push한 뒤 `npm run deploy:web`도 실행해야 운영 사이트에 반영됩니다.** 공개 파일 범위, 확인 절차와 복구 방법은 [WEB_HOSTING.md](WEB_HOSTING.md)를 참고하세요. 기존 장부 서버 `maple-tracker-sync`의 배포와 구분합니다.

## 주요 기능

- 공개 홈: 로그인 없이 판매 손익을 계산하고 산식·기록 사례·제작과 출처를 확인합니다. `/`는 공개 홈, `/?page=home`은 기존 개인 장부이며 로그인 콜백과 저장 방식은 유지합니다.
- 오늘의 플레이 데스크: 빠른 기록·수익·기록 현황을 먼저 보고 플레이 전 계획, 플레이 후 기록, 판매 후 정산으로 이동합니다. 상단 도구 찾기 또는 `Ctrl/⌘+K`로 메뉴와 여섯 계획 도구를 검색합니다. 현황은 기존 장부를 읽어서 표시합니다.
- 자산·성장 계획: 장비별 투자 장부, 부분 판매·분배 정산함, 기록 기준 잔액과 복수 목표, 재획 실측 비교, 시간 예산별 보스 조합, 심볼 예정 비용
- [계산·기록 기준](https://maple-trackers.com/guide/record-principles/): API 제공 범위와 직접 입력, 추정/확정·예정 금액, 백업·정정 원칙
- 재획 회차별 메소·추가 부수입·솔 에르다 조각 기록 및 일일/주간/월간 통계
- 일간·주간·월간 보스 결정석 관리와 난이도·파티 인원·드랍 체크
- 파티장/파티원, 수수료, 사용자 지정 분배율을 반영한 아이템 수익 계산
- 스타포스, 잠재능력, 주문서, 추가 옵션, 원더베리, 로얄스타일, 플래티넘 애플 손익 기록
- NEXON Open API 기반 캐릭터 프로필 등록과 캐릭터 이미지 표시
- 별도 [API 연동 랜딩](https://maple-trackers.com/api/)에서 키 발급과 캐릭터 등록 흐름 안내
- 공개 [사용 가이드](https://maple-trackers.com/guide/)와 [사이트 소개](https://maple-trackers.com/about/) 제공
- 넥슨 계정별 장부 동기화, 기존 API 키 보관함 유지, JSON 백업/복원과 월간 자동 보관
- 강화 API 이력 수집, 추정 지출 검토와 확정 반영. 프렌즈 로그인 서버 설정 및 제한 사항은 [FRIENDS_SETUP.md](FRIENDS_SETUP.md) 참고

## Codex 및 GPT-5.6 활용

이 프로젝트는 Codex와 GPT-5.6을 개발 보조 도구로 활용해, 사용자 피드백을 실제 기능으로 빠르게 반영하는 방식으로 제작했습니다.

- 복잡한 보스·난이도·드랍 아이템 데이터를 단일 데이터 구조로 정리하고, 기존 브라우저 저장 데이터가 깨지지 않도록 마이그레이션 로직을 설계했습니다.
- 재획 기록, 드랍 분배, 솔 에르다 조각 정산, 손익 계산, 주간/월간/일간 초기화 규칙을 구현하고 예외 상황을 점검했습니다.
- 모바일과 PC에서 모두 읽기 쉬운 카드, 표, 입력 폼, 그래프 UI를 반복적으로 개선했습니다.
- NEXON Open API 캐릭터 조회, Cloudflare 암호화 동기화, GitHub Pages 배포 흐름을 연결했습니다.
- 주간 전환 시 기존 기록을 보존하면서 새 주 데이터를 생성하는 복구 로직과 자동화 테스트를 추가했습니다.

AI가 제안한 구현은 실제 사용 흐름과 메이플스토리 보스 규칙에 맞춰 검토하고 수정했으며, 최종 기능과 화면 구성은 사용자 피드백을 바탕으로 결정했습니다.

## 데이터와 개인정보

- 기본 기록은 사용 중인 브라우저에 저장됩니다.
- 넥슨 API 키는 JSON 백업에 포함되지 않습니다.
- 넥슨 계정 장부는 서버가 관리하는 계정별 임의 키로, 기존 API 키 보관함은 API 키에서 파생한 키로 브라우저에서 암호화합니다. 계정 장부는 서버도 암호화 키를 보관합니다.
- 기기 이동이나 장기 보관 전에는 JSON 백업을 함께 만들어 두는 것을 권장합니다.
- 사이트의 자세한 데이터 처리 내용은 [`privacy.html`](privacy.html)에서 확인할 수 있습니다.

## 광고 설정

계산 사례 가이드 3편의 본문 아래에 승인 후 활성화할 수 있는 반응형 AdSense 광고 영역이 준비되어 있습니다. 개인 장부·설정·개인정보 화면에는 광고를 요청하지 않습니다. 기본값은 비활성화이며 광고 설정 전에는 화면에 빈 공간을 만들지 않습니다. 등록, ads.txt, 개인정보 메시지와 배포 절차는 [`ADSENSE_SETUP.md`](ADSENSE_SETUP.md)를 참고하세요.

## UI 검증

- `npm run test:public-home`: 공개 홈 라우팅, 정밀 손익·미판매·입력 오류, 여섯 화면 크기, JavaScript 비활성 본문, 저장소·인증 API 무접근과 장부 왕복 보존을 검사합니다.
- `npm run test:play-desk`: 여섯 화면 크기에서 기록 현황, 도구 검색과 직접 이동, 키보드·초점 복귀, 계정 접근, 원본 장부 불변을 가상 기록으로 검사합니다.
- `npm run test:planner`: 신규 여섯 기능의 계산·UI·원본 보존, 계획 병합/삭제 표식, 장비·심볼 API 소유권/부분 실패, JSON·계정 직렬화, 다섯 화면 폭을 가상 기록으로 검사합니다.
- 계획은 `mapleTracker.v2` 안의 `planner` 영역에 저장합니다. 기존 통계 원본을 자동으로 다시 쓰거나 정산 수익을 중복 반영하지 않습니다. 심볼 비용은 확인한 총액/단계별 금액을 직접 입력하며 보유 메소·시세·실제 판매일은 API 자동 조회 대상이 아닙니다.
- 넥슨 로그인으로 새 장비·심볼 조회를 사용하려면 웹 배포와 함께 장부 API Worker의 `friends.mjs`도 배포합니다. 기존 운영자 `NEXON_API_KEY` Secret과 로그인 권한을 그대로 사용합니다.
- `assets/workspace.css`, `assets/workspace.js`는 기록 저장 구조와 분리된 화면·탐색 계층입니다.
- `npm run test:data-safety`: 재획 보호 및 클라우드 이력 회귀 테스트
- `npm run test:enhancements`: 강화 추정, 중복 방지, OAuth 보안 및 지출 반영 회귀 테스트
- `npx playwright install chromium` 후 `npm run test:ui`: 임시 로컬 서버와 격리된 브라우저에서 PC·모바일 화면, 메뉴, 저장, 백업, 드랍 기록 유지 확인
- 설치된 Chrome을 사용하려면 `PLAYWRIGHT_CHANNEL=chrome` 환경 변수를 지정합니다.
- 테스트는 가상 기록만 사용하며 실제 서비스와 외부 API 요청을 차단합니다. 캡처는 Git에서 제외된 `.tools/ui-review/`에 저장됩니다.
- `npm run prepare:android-web`: 같은 UI를 Android 웹 자산에도 반영합니다.
