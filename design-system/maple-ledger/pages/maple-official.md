# 메이플 공식 홈페이지 느낌의 장부 · 2026-11-11

이번 사용자의 공식 홈페이지 참고 요청은 이전의 어두운 테마 유지보다 우선한다. 첫 진입은 기존 장부로 유지한다.

## 직접 확인한 참고

https://maplestory.nexon.com/home/main 의 실제 화면을 PC·모바일에서 확인했다. 백색 바탕, 가로 메뉴, 넓은 둥근 배너, 아주 밝은 회색·보라색 구획, 보라빛 계정 카드와 진한 로그인, 소수의 주황색 동작이 특징이다. 현재 참고 화면의 점검 안내·공식 로고·게임 시작 버튼이나 고정 최소 너비는 가져오지 않는다.

## 메계부의 디자인 기준

| 역할 | 색 |
| --- | --- |
| 전체 바탕 | `#F4F4F8` |
| 장부 패널 | `#FFFFFF` |
| 제목·본문 | `#292A3B` |
| 보조 글자 | `#626476` |
| 주요 동작 | `#FF8545` (진한 글자와 사용) |
| 계정·강조 | `#73748E` |

금액은 짙은 주황 `#A54B16`, 수입은 녹색 `#16725A`, 지출은 적색 `#B83A49`로 읽히게 한다. 한국어 UI는 기존 자체 호스팅 SUIT, 브랜드·짧은 배너 제목은 MaplestoryTitle이다.

```text
메계부 브랜드      내 기록  보스  수입·지출  통계·계획  도움말
현재 화면 설명                         메뉴 찾기  넥슨 로그인  백업
넓은 버섯 일러스트와 빠른 기록                     보라빛 계정 패널
기록한 수입·지출                                  확인할 기록
주간 진행과 접어서 보는 결산·계획·계산 근거
```

PC는 왼쪽 고정 메뉴 대신 목적별 가로 메뉴를 쓴다. 각 하위 메뉴는 클릭·키보드로 열고 Esc·바깥 클릭·선택으로 닫는다. 현재 위치를 글자와 밑줄로 표시한다. 모바일은 기존 전체 메뉴와 하단 탐색을 유지한다. 기존 계정 노드를 복제하지 않는다.

## 독창성과 절제

공식 홈페이지의 편집 원칙을 따르되 메계부 자체 버섯 배경·메소 아이콘·기록 버튼·합계를 중심에 놓는다. 홍보 포털, 가짜 게임 시작, 공식 제휴 표시는 만들지 않는다. 큰 일러스트는 홈 배너 한 곳에 집중하고 입력 면은 불투명한 흰색으로 둔다. 내용이 모두 같은 둥근 카드처럼 보이지 않게 상단 메뉴, 계정, 기록 결과, 보조 펼치기에 다른 위계를 준다.

ui-ux-pro-max 검색의 일반 포털 추천은 기능 위계·대비만 참고했다. 파랑/초록의 일반 기업용 팔레트와 라틴 글꼴 추천은 요청한 참고 사이트 및 한국어 장부와 맞지 않아 채택하지 않았다.

## 보존·검증

장부·인증·복구 데이터는 디자인 코드가 쓰지 않는다. 320~1920px, 입력 저장·백업, 계정·모바일 메뉴, 키보드·확대·대비, 실제 12개 선택과 13번째 차단, 경매장 3%와 기존 거래 보존을 확인한다.
