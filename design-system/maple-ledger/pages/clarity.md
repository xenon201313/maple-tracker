# 기록을 먼저 보는 메계부 · 2026-11-05

## 문제와 기준

홈에 기록·결산·예측·시세·계획·안내가 모두 펼쳐져 있어 첫 사용자가 어디서 시작할지 판단하기 어렵다. 같은 완료 체크가 처치와 판매를 뜻하는 문제도 있다. 핵심은 색만 바꾸는 것이 아니라 행동과 정보의 순서를 정리하는 것이다.

## 유지할 개성

- 메이플 버섯 배경은 상단 삽화에 집중하고 입력 바탕은 불투명하게 한다.
- 차콜 `#171B1E`, 장부 `#22282C`, 경계 `#65747C`, 메소 `#FFD083`, 글자 `#F4F2EB`, 보조 `#B8C4C7`를 유지한다.
- SUIT는 본문·수치·버튼, 메이플 제목체는 상단 브랜드와 짧은 제목에 쓴다.
- 실제 메소·결정석 이미지로 기록 종류를 구분하고 장식 효과와 카드의 반복은 줄인다.

## 구성

```text
항상 보이는 메뉴 / 메뉴 찾기 / 넥슨 로그인 / 백업
짧은 기록장 소개 + 계정 상태
재획 기록   보스 기록   지출 기록
이번 주·이번 달 기록 합계 / 오늘 기록·미정산 확인
주간 보스 진행
월간 결산 [펼치기]   정산·계획 도구 [펼치기]
수익 흐름·예상 금액 / 시세 / 누적 기록 / 백업 [각각 펼치기]
처음 사용·계산 사례 [펼치기]
```

왼쪽 정렬, 본문 16px, 보조 설명 13~14px, 줄 길이 75자 이내를 기본으로 한다. 주요 기록은 모바일 첫 화면 안에 보이게 하고 상세 설명은 짧은 문구와 링크로 제공한다. 페이지마다 첫 입력·기간·저장 동작의 위치를 일정하게 한다. 일간 보스의 처치와 판매는 별도 체크와 설명으로 구분한다.

## 참고와 적용 범위

[Maple.GG](https://maple.gg/)의 주 작업 우선, [MapleScouter](https://maplescouter.com/ko)의 목적별 도구 묶음, [츄츄지지](https://chuchu.gg/)의 주요 기능과 공지 분리를 참고했다. 화면이나 문구를 복제하지 않는다. 검색창을 중심에 놓는 전적 사이트와 달리 메계부의 주 작업은 입력이므로 세 가지 기록 버튼과 기록 합계를 우선한다. 공개 포털로 진입점을 바꾸거나 밝은 테마를 재도입하지 않는다.

## 안전·접근성

접기는 원래 DOM과 이벤트를 보존하고 저장소에 쓰지 않는다. 검색·초점 이동으로 접힌 영역에 접근할 때 조상 영역을 먼저 연다. 로그인·계정 선택은 단일 인스턴스를 유지한다. 320px부터 큰 화면, 키보드, 큰 금액, 확대 글꼴, 합성 장부 저장·백업·왕복을 검증한다.
