# 메계부 UI 개편 기준 · 2026-10-31

## 목적과 방향

메이플스토리 이용자가 재획·보스 수입, 아이템 판매와 지출을 기록하고 검산하는 개인 장부다. 공개 포털로 진입점을 바꾸지 않는다. 기존 버섯 이미지와 메소 아이콘을 살린 **모험가의 정산대**를 디자인 기준으로 삼는다. 기존의 긴 카드 나열을 빠른 기록, 결과, 확인할 일, 상세 분석으로 나눈다.

## 색과 글꼴

| 역할 | 값 | 사용 |
| --- | --- | --- |
| 바탕 | `#171B1E` | 차분한 차콜 작업 공간 |
| 장부 표면 | `#22282C` | 입력·결산 본문 |
| 올린 표면 | `#2C3438` | 탐색·입력 보조 영역 |
| 경계 | `#455057` | 구획, 입력 경계 |
| 메소 금색 | `#FFD083` | 주요 기록 동작, 메소 수치 |
| 글자 | `#F4F2EB` | 본문 |

보조 글자는 `#B8C4C7`, 수입·완료는 `#91D5BA`, 지출·오류는 `#FFADB2`를 사용한다. 상태에는 색과 함께 문구를 쓴다. 한국어 본문은 공식 배포본을 직접 호스팅한 SUIT Variable, 브랜드와 홈 핵심 제목은 기존 MaplestoryTitle이다. 큰 금액에는 tabular 숫자를 적용하고 문구는 강제로 자르지 않는다.

## 레이아웃

```text
┌ 메뉴 ─────┬ 현재 페이지                 검색 · 넥슨 로그인 · 백업 ┐
│ 내 장부   │ 모험 장부 소개·초기화 일정       계정 연결·기기 보관   │
│ 기록      │ 재획 기록 / 보스 체크 / 지출 기록                     │
│ 보스      ├ 수익 요약                      오늘 기록·미정산 확인 ┤
│ 결산·계획 │ 보스 진행 / 월간 결산          목적별 계획 도구      │
│ 도움말    │ 상세 추이·시세·백업 / 검산 예제·계산 근거·제작 문의   │
└───────────┴────────────────────────────────────────────────────┘
```

모바일은 같은 읽기 순서로 한 열을 사용한다. 고정 헤더의 로그인 글자는 유지한다. 큰 계정 안내가 반복 기록을 밀어내지 않도록 안내는 접고 상태·실제 연결 동작을 먼저 보여준다. 일반 지출 입력을 강화 API 목록보다 위로 옮기고, 화면 상단에서 각 영역으로 바로 이동한다. 손익은 상품 선택, 입력, 결과, 저장 기록의 경계를 분명히 한다.

## 신뢰를 드러내는 방식

- 로그인이나 기록이 없는 방문자도 공개 검산 도구·예제·제작 안내를 찾을 수 있다.
- 실제 기록, 판매 전 계산값, 추정 강화 비용과 계획 예산을 문구로 구분한다.
- 계산식·수수료·분배·API 제공 범위와 문의/정정 경로를 관련 화면에서 연결한다.
- 제작자·경력·이용자 수·후기·공식 보증을 만들어 넣지 않는다. E-E-A-T를 인증 배지나 AdSense 승인 점수처럼 표현하지 않는다.
- 같은 레이아웃을 모든 구획에 반복하지 않는다. 기록 버튼, 장부 수치, 확인할 일, 읽기 자료는 서로 다른 위계를 갖는다.

## 검토한 선택

ui-ux-pro-max의 `gaming personal ledger dashboard` 검색은 3D 쇼케이스를 추천했지만 반복 입력 작업에 맞지 않아 채택하지 않았다. `personal finance tracking dashboard`의 정보 위계·대비 원칙을 참고하되 유리 효과·라틴 손글씨·일반 금융 서비스 팔레트는 적용하지 않았다. 버섯·메소와 한국어 수치 입력에 맞춘 위 기준을 최종 적용한다. 기존 밝은 공개 포털 개편은 재적용하지 않는다.

## 보존과 검증

장부·복구·로그인·클라우드·계산 함수·라우팅 계약을 유지한다. 새 화면 코드는 표시와 탐색만 맡고 저장소를 쓰지 않는다. 키보드, 320~1920px, 큰 금액·긴 이름, 초점·모달·딥링크, 장부 불변과 실제 입력·백업·계정 왕복을 합성 데이터로 검증한다.
