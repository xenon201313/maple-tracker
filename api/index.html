넥슨 로그인·API 연동

넥슨 로그인 또는 개인 API 키 등록 중 한 가지 방식으로 캐릭터 정보를 연결할 수 있습니다. 넥슨 로그인만으로 본인 캐릭터의 이미지·전투력·경험치·보스 진행과 강화 이력을 조회하고, 계정 장부를 저장할 수 있습니다.

넥슨 로그인·계정 장부 열기 캐릭터 등록·개인 API 키 강화 이력·수기 지출 열기 NEXON Open API 키 발급
기본 장부는 API 연결 없이도 사용할 수 있습니다. API 키 등록이나 프렌즈 로그인만으로 기존 기록을 다시 만들 필요는 없습니다. 이미 수기로 적은 같은 비용은 API에서 중복 반영하지 마세요.

넥슨 로그인으로 기록 이어가기

  1. 홈에서 넥슨 로그인을 누릅니다. 개인 기기에서 다음 방문에도 로그인하려면 이 기기에서 자동 로그인을 선택하세요. 공용 기기에서는 체크를 비워 두세요.
  2. 처음 연결할 때는 이 기기의 기존 기록을 계정에 연결할지, 계정에 저장된 장부를 열지 확인합니다. 전환 전 원본과 복구 기록은 이 기기에 별도로 보관합니다.
  3. 자동 로그인을 켠 브라우저를 다시 열면, 로그인이 유효한 동안 전에 선택한 장부로 이어집니다. 다른 기기에서는 같은 넥슨 계정으로 로그인한 뒤 사용할 장부를 한 번 선택하세요.

캐릭터 등록에서 내 캐릭터 조회를 눌러 본인 캐릭터를 선택합니다. 이미지·전투력·경험치와 보스 완료 상태를 가져오며, 개인 API 키를 추가로 등록할 필요는 없습니다. 기존에 이미지나 상세 정보가 없던 캐릭터도 개별 갱신 또는 전체 새로고침으로 갱신할 수 있습니다.

보스 완료 상태를 갱신해도 이미 기록한 파티 인원과 드랍 판매가는 유지됩니다. 자동 로그인은 이 브라우저에서 최대 14일 유지됩니다. 넥슨 인증이 먼저 만료되면 다시 로그인하세요. 두 기기에서 서로 다르게 편집한 기록이 있으면 어느 장부를 사용할지 확인합니다.

로그아웃해도 저장한 장부는 남습니다. 공용 기기에서는 필요한 백업을 보관하고 사이트 데이터도 직접 정리해 주세요. 개인 API 키 보관함은 계정 장부와 별도로 유지됩니다.

2

키 저장

3

캐릭터 추가

캐릭터 이름을 입력하면 프로필을 조회합니다. 이후 새로고침으로 최신 정보와 진행 상태를 갱신할 수 있습니다.

본서버 1.2.420부터 보스 스케줄러 정보에 익스트림 림보·발드릭스가 추가됐습니다. 정보 갱신으로 완료 상태를 확인하더라도 드랍 아이템의 실제 획득·판매 금액은 직접 확인해 기록합니다.

소울 잠재능력 이력에서 미라클 타임 적용 여부를 확인할 수 있습니다. 재설정 비용은 변경 전 등급의 공식 단가와 시도 횟수로 계산합니다. 이미 장부에 적은 비용은 조회 결과에서 제외할 수 있습니다.

강화 이력 연결: 두 가지 방식

지출 기록에서 전체 이력을 열고 넥슨 로그인 또는 등록한 개인 API 키를 선택하세요. 기간을 정하고 이력 가져오기를 누르면 스타포스, 잠재능력 재설정, 큐브 사용, 소울 잠재능력 기록을 조회합니다. 날짜는 한국 시간 기준이며 넥슨이 제공하는 최근 2년 범위에서 선택할 수 있습니다. 소울 잠재능력은 기능이 도입된 2026년 9월 17일부터 조회합니다.

넥슨 프렌즈

연결 방식을 넥슨 프렌즈로 선택하고 넥슨 로그인 버튼을 누릅니다. 넥슨 화면에서 계정과 요청 권한을 확인한 뒤 메계부로 돌아와 조회 날짜를 고르고 이력을 가져옵니다.

등록한 개인 API 키

캐릭터 등록 화면에 저장한 API 키를 사용하려면 연결 방식을 등록한 개인 API 키로 바꿉니다. 조회 날짜를 선택하고 해당 키로 조회 가능한 강화 이력을 가져옵니다.

넥슨 Open ID 프로덕션 승인을 받아 일반 사용자도 로그인할 수 있습니다. 새로 추가된 소울 잠재능력 권한을 사용하려면 다시 로그인하여 데이터 제공에 동의해야 할 수 있습니다. 소울 이력 권한이 없어도 다른 강화 이력과 수기 기록은 계속 사용할 수 있습니다.

잠재능력 탭에서는 메소 재설정과 큐브 사용 이력을 함께 봅니다. 메소 사용액과 큐브 환산액은 구분해서 표시하며, 무료·캐시 큐브를 사용했다는 사실만으로 메소 지출을 확정하지 않습니다. 실제 메소로 구입한 비용이 있다면 그 금액을 확인하세요.

가져온 이력은 지출 반영 전까지 통계에 포함되지 않습니다. 상세 내역과 최종 반영 금액을 확인한 뒤 지출 반영을 누릅니다. 확정한 금액을 취소하면 API 원본 이력은 남고 지출 반영 상태가 바뀝니다. 같은 비용을 이미 다른 화면에서 기록했다면 다시 확정하지 마세요.

현재 직접 기록하는 강화

전체 이력에서 가져온 강화 결과와 직접 기록한 지출을 날짜순으로 확인할 수 있습니다. 소울 증폭 시도·재료 구입비와 고급 어빌리티는 직접 기록합니다.

  • 소울 에테르에서 재료 구입비와 증폭 비용을 기록합니다. 소울 잠재 재설정을 직접 기록할 때는 변경 전 등급과 횟수를 사용합니다. 예를 들어 에픽에서 두 번 재설정하면 4,000만 × 2회로 8,000만 메소입니다. 공식 등급별 비용표
  • 고급 어빌리티: 명예의 훈장 구입비와 재설정에 직접 사용한 메소를 함께 기록합니다. 보유 명성치와 무료 훈장은 비용으로 환산하지 않습니다.
  • 직접 입력: 스타포스·잠재능력·주문서·추가옵션·어빌리티 비용을 API 없이 기록할 때 사용합니다.

수기 기록은 저장하면 지출에 반영됩니다. API 이력이나 메소 지출 입력에 같은 비용을 다시 넣지 마세요. 장부에 저장하지 않는 계산 예제에서 비용과 판매 수입을 먼저 비교할 수 있습니다.
