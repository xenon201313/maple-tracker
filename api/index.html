넥슨 로그인·API 연동

넥슨 로그인으로 계정 장부를 저장하고, 내 캐릭터 목록·보스 진행·강화 이력을 가져올 수 있습니다. 캐릭터 이미지·전투력·경험치의 상세 조회와 기존 클라우드 동기화에는 개인 API 키 방식도 계속 사용할 수 있습니다.

넥슨 로그인·계정 장부 열기 캐릭터 등록·개인 API 키 강화 이력·수기 지출 열기 NEXON Open API 키 발급
기본 장부는 API 연결 없이도 사용할 수 있습니다. API 키 등록이나 프렌즈 로그인만으로 기존 기록을 다시 만들 필요는 없습니다. 이미 수기로 적은 같은 비용은 API에서 중복 반영하지 마세요.

넥슨 로그인으로 기록 이어가기

  1. 홈에서 넥슨 로그인을 선택하고 넥슨의 공식 로그인·동의 화면을 완료합니다.
  2. 처음 연결할 때는 이 기기의 기존 기록을 계정에 연결할지, 계정에 저장된 장부를 열지 확인합니다. 전환 전 원본과 복구 기록은 이 기기에 별도로 보관합니다.
  3. 계정 장부를 선택하면 이후 변경이 동기화됩니다. 다른 기기에서도 같은 넥슨 계정으로 로그인하여 같은 장부를 열 수 있습니다.

캐릭터 목록에서는 이름·월드·직업·레벨을 불러와 등록할 수 있습니다. 스케줄러에서 보스 완료 상태를 가져오며, 이미 기록한 파티 인원과 판매가·드랍을 자동으로 추정하지 않습니다. 다른 기기의 변경과 충돌하면 자동 덮어쓰기를 멈추고 사용할 기록을 확인합니다.

로그아웃해도 저장한 장부는 남습니다. 공용 기기에서는 필요한 백업을 보관하고 사이트 데이터도 직접 정리해 주세요. 개인 API 키 보관함은 계정 장부와 별도로 유지됩니다.

캐릭터 프로필 연결: 개인 API 키

처음 한 번만 진행하면 됩니다.

1

API 키 발급

NEXON Open API에서 애플리케이션을 등록합니다. 게임은 메이플스토리, 개발 환경은 WEB으로 선택하고 서비스 단계를 설정합니다.

2

키 저장

나만의 메계부 캐릭터 등록 화면에 발급받은 API 키를 붙여 넣고 저장합니다.

3

캐릭터 추가

캐릭터 이름을 입력하면 프로필을 조회합니다. 이후 새로고침으로 최신 정보와 진행 상태를 갱신할 수 있습니다.

강화 이력 연결: 두 가지 방식

지출 기록의 스타포스·잠재능력·소울 에테르 탭에서 연결 방식을 선택합니다. 개인 API 키 등록과 넥슨 로그인은 서로 다른 연결 방식입니다.

넥슨 프렌즈

연결 방식을 넥슨 프렌즈로 선택하고 넥슨 로그인 버튼을 누릅니다. 넥슨 화면에서 계정과 요청 권한을 확인한 뒤 메계부로 돌아와 조회 날짜를 고르고 이력을 가져옵니다.

등록한 개인 API 키

캐릭터 등록 화면에 저장한 API 키를 사용하려면 연결 방식을 등록한 개인 API 키로 바꿉니다. 조회 날짜를 선택하고 해당 키로 조회 가능한 강화 이력을 가져옵니다.

넥슨 Open ID 프로덕션 승인을 받아 일반 사용자도 로그인할 수 있습니다. 새로 추가된 소울 잠재능력 권한을 사용하려면 다시 로그인하여 데이터 제공에 동의해야 할 수 있습니다. 소울 이력 권한이 없어도 다른 강화 이력과 수기 기록은 계속 사용할 수 있습니다.

잠재능력 탭에서는 메소 재설정과 큐브 사용 이력을 함께 봅니다. 메소 사용액과 큐브 환산액은 구분해서 표시하며, 무료·캐시 큐브를 사용했다는 사실만으로 메소 지출을 확정하지 않습니다. 실제 메소로 구입한 비용이 있다면 그 금액을 확인하세요.

가져온 이력은 지출 반영 전까지 통계에 포함되지 않습니다. 상세 내역과 최종 반영 금액을 확인한 뒤 지출 반영을 누릅니다. 확정한 금액을 취소하면 API 원본 이력은 남고 지출 반영 상태가 바뀝니다. 같은 비용을 이미 다른 화면에서 기록했다면 다시 확정하지 마세요.

현재 직접 기록하는 강화

상단 강화 메뉴는 스타포스 · 잠재능력 · 소울 에테르 · 고급 어빌리티 · 직접 입력입니다. 소울 잠재능력 재설정 이력은 API로 조회할 수 있지만, 소울 증폭 시도·재료 구입비와 고급 어빌리티 재설정 비용은 제공되는 이력 API가 없어 직접 기록합니다.

  • 소울 에테르: 1~4단계 에테르의 실제 구입 단가·수량과 증폭 메소를 입력합니다. 소울 잠재 재설정은 API 이력을 확인하여 반영하거나 수기로 기록할 수 있습니다. 같은 비용은 한 방식으로만 반영하세요.
  • 고급 어빌리티: 명예의 훈장 구입비와 재설정에 직접 사용한 메소를 함께 기록합니다. 보유 명성치와 무료 훈장은 비용으로 환산하지 않습니다.
  • 직접 입력: 스타포스·잠재능력·주문서·추가옵션·어빌리티 비용을 API 없이 기록할 때 사용합니다.

수기 기록은 저장하면 지출에 반영됩니다. API 이력이나 메소 지출 입력에 같은 비용을 다시 넣지 마세요. 장부에 저장하지 않는 계산 예제에서 비용과 판매 수입을 먼저 비교할 수 있습니다.

넥슨 로그인 후 계정 장부를 선택하면 같은 계정으로 기기 간 기록을 이어갑니다. 기존 개인 API 키 보관함도 별도로 유지됩니다. 계정 방식은 서버가 계정 암호화 키를 보관하며, 자세한 범위는 개인정보 안내에서 확인할 수 있습니다. 기기 이동 전에는 JSON 백업도 보관하세요.
