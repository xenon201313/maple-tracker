NEXON Open API 캐릭터 연동

API 키를 한 번 등록하면 캐릭터명만으로 월드, 직업, 레벨, 캐릭터 이미지와 게임 진행 정보를 불러올 수 있습니다.

나만의 메계부에서 연동 시작 NEXON Open API 키 발급
이미 API 키가 있다면 첫 번째 버튼을 누른 뒤 키를 저장하고 캐릭터 이름을 입력하세요. 기존 수익 기록은 그대로 유지됩니다.

연동 순서

처음 한 번만 진행하면 됩니다.

1

API 키 발급

NEXON Open API에서 애플리케이션을 등록합니다. 게임은 메이플스토리, 개발 환경은 WEB으로 선택하고 서비스 단계를 설정합니다.

2

키 저장

나만의 메계부 캐릭터 등록 화면에 발급받은 API 키를 붙여 넣고 저장합니다.

3

캐릭터 추가

캐릭터 이름을 입력하면 프로필을 조회합니다. 이후 새로고침으로 최신 정보와 진행 상태를 갱신할 수 있습니다.

저장과 기기 이동

키와 기록을 분리해 관리합니다.

API 키 보호

API 키는 JSON 백업에 포함하지 않습니다. 다른 사람에게 키를 공유하지 마세요.

암호화 클라우드 동기화

API 키를 등록하면 암호화된 동기화를 사용해 다른 기기에서 기록을 이어서 불러올 수 있습니다.
