나만의 메계부를 만든 이유

재획 메소, 솔 에르다 조각, 보스 결정석과 드랍 아이템을 서로 다른 메모장에 적던 불편을 줄이고, 실제로 내게 들어온 메소를 한곳에서 확인하기 위해 만든 개인 수익 기록 도구입니다.

기록의 기준

표면적인 판매 가격보다 실제 수령액을 보여주는 것을 우선합니다. 결정석은 파티 인원으로 나눈 몫을 계산하고, 드랍 아이템은 판매 수수료와 파티 분배율을 적용합니다. 보스 드랍은 미판매 상태라면 가격을 비워 보유 기록만 남깁니다. 손익 계산기의 결과물은 판매 완료로 표시한 항목만 수익에 반영합니다.

일간, 주간과 월간 보스는 초기화 주기가 다르므로 별도 화면과 기간으로 관리합니다. 재획 기록 역시 같은 날짜에 여러 회차를 나누어 저장하며, 솔 에르다 조각의 가격과 환산 선택은 각 회차에 고정합니다.

이 사이트가 제공하는 것

사냥 수익 기록

캐릭터와 회차별로 획득 메소, 추가 부수입, 솔 에르다 조각을 기록합니다. 조각을 보유할 때와 실제로 판매했을 때를 분리해 중복 계산을 줄입니다.

보스 수익 계산

난이도, 파티 인원, 결정석, 드랍 아이템, 판매 수수료와 사용자 지정 분배율을 함께 계산합니다. 월간 보스 수익은 주간 보스 합계에서 분리합니다.

손익과 지출

손익 계산기에서 원더베리·로얄스타일·플래티넘 애플의 투입 비용과 판매 완료된 결과물을 비교하고, 장비·펫·코디·도핑처럼 직접 사용한 메소를 별도의 지출로 남깁니다.

통계와 목표

최근 기록, 주간·월간 결산, 획득 아이템과 목표 금액 진행을 확인합니다. 저장된 기록만으로 계산하며 임의의 예상 수익을 실제 수익에 넣지 않습니다.

데이터와 API 원칙

기본 기록은 이용자의 브라우저에 저장되며 운영자가 개인 장부를 직접 열람하지 않습니다. 선택적으로 사용하는 클라우드 동기화는 브라우저에서 기록을 암호화한 뒤 전송하도록 구성했습니다. 중요한 기록은 JSON 백업도 함께 보관하는 것을 권장합니다.

캐릭터 프로필과 공개 게임 정보 조회에는 NEXON Open API를 사용합니다. 이 사이트는 NEXON의 공식 서비스가 아니며 API 키는 이용자가 직접 발급하고 관리합니다. 키는 JSON 백업에 포함하지 않습니다.

운영과 광고 원칙

기능 개선은 실제 사용 중 받은 불편 제보와 재현 가능한 오류를 우선해 반영합니다. 기존 브라우저 기록이 깨지지 않도록 저장 구조 변경에는 호환 처리와 데이터 보존 검사를 함께 적용합니다.

사이트 운영비를 보조하기 위해 Google AdSense를 사용할 수 있지만, 광고는 승인 이후 계산 사례 가이드 본문 아래에 제한적으로 표시합니다. 개인 장부 입력 화면과 개인정보 안내에는 광고를 요청하지 않습니다. 광고를 콘텐츠처럼 보이게 만들거나 클릭을 유도하지 않으며, 광고 미송출 상태에서는 불필요한 빈 공간을 남기지 않습니다.

가이드의 작성과 수정 기준

계산 사례는 이 기록장의 입력 항목과 계산 방식에 맞춰 작성합니다. 예시의 가격·수량은 이해를 돕기 위한 가상 값이며 실제 시세, 평균 수익이나 수익 보장을 뜻하지 않습니다. 계산 과정과 현재 기능의 한계를 함께 밝히고, 기능이 달라지거나 오류가 확인되면 관련 설명을 수정합니다.

게임 이미지와 NEXON Open API 정보의 권리는 각 권리자에게 있습니다. 비공식 기록 도구의 설명과 게임의 공식 규칙을 구분해 안내합니다.

제작과 문의
