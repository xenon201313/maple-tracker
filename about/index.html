제작과 운영 기준

메계부는 누가, 어떤 기준으로 만들까요?

메이플스토리 크로아 월드의 얀보가 재획·보스 수익을 따로 적던 불편에서 시작한 개인 장부입니다. 기록 전에도 판매 손익과 파티 분배를 계산하고, 계산식과 입력 조건을 함께 읽을 수 있도록 공개했습니다.

운영·기록 기준: 크로아/얀보 안내 수정 2026-10-28 NEXON 비공식 도구
누가 운영하나요?

크로아/얀보가 기록 기준을 정하고 이용 중 받은 제보를 반영합니다. 공개 소스와 이력에서 변경을 확인할 수 있습니다.

설명은 어떻게 확인하나요?

가상 금액을 사용한 예제, 계산 과정과 직접 바꿔 보는 계산기를 함께 제공합니다. 합계에 들어가는 기준도 공개합니다.

틀린 내용은 어디로 보내나요?

오류 제보 방법에 따라 화면과 계산 조건을 남겨 주세요. 개인 장부 전체·API 키·로그인 정보는 보내지 않습니다.

실제 사용 중 생긴 문제를 기록 방식으로 해결합니다

기능 이름만 늘리기보다 어디서 같은 금액이 겹치고 어떤 조건이 빠졌는지를 확인합니다. 아래는 이 기록장의 계산·저장 방식을 정할 때 반영한 사례입니다.

기록의 기준

표면적인 판매 가격보다 실제 수령액을 보여주는 것을 우선합니다. 결정석은 파티 인원으로 나눈 몫을 계산하고, 드랍 아이템은 판매 수수료와 파티 분배율을 적용합니다. 보스 드랍은 미판매 상태라면 가격을 비워 보유 기록만 남깁니다. 손익 계산기의 결과물은 판매 완료로 표시한 항목만 수익에 반영합니다.

일간, 주간과 월간 보스는 초기화 주기가 다르므로 별도 화면과 기간으로 관리합니다. 재획 기록 역시 같은 날짜에 여러 회차를 나누어 저장하며, 솔 에르다 조각의 가격과 환산 선택은 각 회차에 고정합니다.

이 사이트가 제공하는 것

기록을 시작하기 전에도 보스 분배 계산기와 판매 손익·강화 비용 계산기를 사용할 수 있습니다. 판매가와 분배 조건, 강화 조건과 실제 시도 횟수로 결과를 구하며 입력은 저장하지 않습니다.

사냥 수익 기록

캐릭터와 회차별로 획득 메소, 추가 부수입, 솔 에르다 조각을 기록합니다. 조각을 보유할 때와 실제로 판매했을 때를 분리해 중복 계산을 줄입니다.

보스 수익 계산

난이도, 파티 인원, 결정석, 드랍 아이템, 판매 수수료와 사용자 지정 분배율을 함께 계산합니다. 월간 보스 수익은 주간 보스 합계에서 분리합니다.

손익과 지출

손익 계산기에서 원더베리·로얄스타일·플래티넘 애플과 기간 한정 상품의 투입 비용과 판매 완료된 결과물을 비교합니다. 판매가 끝난 상품의 신규 입력은 종료 일정에 맞춰 숨기며, 종료 전 저장한 기록은 유지합니다.

강화 지출은 스타포스·잠재능력·소울 에테르·고급 어빌리티·직접 입력 탭에서 관리합니다. 에테르와 명예의 훈장 구입비, 실제 사용 메소를 수기로 기록할 수 있으며, 보유 명성치나 무료 재료는 메소 지출로 환산하지 않습니다.

통계와 목표

최근 기록, 주간·월간 결산, 획득 아이템과 목표 금액 진행을 확인합니다. 저장된 기록만으로 계산하며 임의의 예상 수익을 실제 수익에 넣지 않습니다.

기록을 다음 계획에 활용하기

장비별 투자 장부는 구입비와 연결한 강화 지출을 모아 보고, 미정산함은 획득일과 실제 판매일·파티 분배 상태를 구분합니다. 자금 계획은 직접 입력한 시작 잔액과 이후 기록을 바탕으로 목표와 준비금을 배분합니다. 이 화면의 합계는 기존 지출이나 판매 수익에 같은 거래를 다시 더하지 않는 방식으로 확인합니다.

재획 비교는 실제 사냥 시간·사냥터·사용 조건을 직접 기록해 비교하고, 보스 계획은 남은 시간 안에 돌 보스 조합을 검토합니다. 심볼 예산은 현재 정보와 목표 조건에서 앞으로 쓸 비용을 준비하는 용도입니다. 예정 비용과 예상 수익은 확정된 지출·실제 수입과 별도로 표시합니다.

계산 원칙과 API·직접 입력의 구분 읽기

데이터와 API 원칙

기본 기록은 이용자의 브라우저에 저장됩니다. 넥슨 로그인 후 계정 장부를 선택하면 암호화한 기록을 계정 보관함에 동기화하며, 기존 개인 API 키 방식도 별도로 유지됩니다. 계정 방식은 서버도 암호화 키를 보관하므로 자세한 처리 범위는 개인정보 안내에서 확인하세요. 중요한 기록은 JSON 백업도 함께 보관하는 것을 권장합니다.

넥슨 로그인만으로 본인 캐릭터의 이미지·전투력·경험치·보스 진행 상태와 스타포스·잠재능력·큐브·소울 잠재능력 이력을 조회합니다. 개인 API 키 등록은 별도로 선택할 수 있는 연결 방식이며, 넥슨 로그인과 함께 등록할 필요는 없습니다. 소울 증폭과 재료 구입비, 고급 어빌리티 비용은 수기로 기록합니다. 가져온 강화 이력은 최종 금액을 확인해야 지출에 반영됩니다. 이 사이트는 NEXON의 공식 서비스가 아니며 API 키는 JSON 백업에 포함하지 않습니다.

운영과 광고 원칙

기능 개선은 실제 사용 중 받은 불편 제보와 재현 가능한 오류를 우선해 반영합니다. 기존 브라우저 기록이 깨지지 않도록 저장 구조 변경에는 호환 처리와 데이터 보존 검사를 함께 적용합니다.

사이트 운영비를 보조하기 위해 Google AdSense를 사용할 수 있지만, 광고는 승인 이후 계산 사례 가이드 본문 아래에 제한적으로 표시합니다. 개인 장부 입력 화면과 개인정보 안내에는 광고를 요청하지 않습니다. 광고를 콘텐츠처럼 보이게 만들거나 클릭을 유도하지 않으며, 광고 미송출 상태에서는 불필요한 빈 공간을 남기지 않습니다.

가이드의 작성과 수정 기준

계산 사례는 이 기록장의 입력 항목과 계산 방식에 맞춰 작성합니다. 예시의 가격·수량은 이해를 돕기 위한 가상 값이며 실제 시세, 평균 수익이나 수익 보장을 뜻하지 않습니다. 계산 과정과 현재 기능의 한계를 함께 밝히고, 기능이 달라지거나 오류가 확인되면 관련 설명을 수정합니다.

게임 이미지와 NEXON Open API 정보의 권리는 각 권리자에게 있습니다. 비공식 기록 도구의 설명과 게임의 공식 규칙을 구분해 안내합니다.

기획과 기록 기준은 운영자의 게임 사용 경험 및 이용자 제보를 바탕으로 정합니다. 코드 구현·오류 수정·문서 정리에는 AI 개발 보조 도구를 활용하며, 계산 예제와 변경된 저장 동작은 가상 기록으로 검토합니다. 자동으로 생성한 설명을 게임의 공식 답변이나 전문가의 보증으로 제시하지 않습니다.

틀린 계산이나 설명을 발견했을 때

오류는 GitHub 이슈로 제보할 수 있습니다. 사용한 화면, 기록 날짜, 파티 인원·수수료 등 계산 조건, 기대한 금액과 실제 표시 금액을 적어 주세요. 화면을 첨부할 때에는 API 키·로그인 정보·개인 장부 전체를 가려 주세요.

제보된 조건을 가상 기록으로 재현하고 계산식·게임 규칙·API 응답 중 차이가 생긴 지점을 확인합니다. 수정 시 적용 날짜와 영향을 받는 항목을 안내하고, 공식 규칙을 인용한 가이드는 출처 링크와 검토일도 함께 갱신합니다. 기록이 사라졌다면 복원 전 현재 상태를 먼저 백업해 주세요.

현재 게임 규칙은 메이플스토리 공식 업데이트, API 제공 범위와 갱신 조건은 NEXON 공식 API 문서를 우선합니다. 장부의 기록 기준은 계산·정산 원칙에서 확인할 수 있습니다.

제작과 문의

나만의 메계부는 메이플스토리 크로아 월드에서 플레이하는 얀보가 개인 기록용으로 시작해 공개한 프로젝트입니다. 소스와 변경 이력은 GitHub 저장소에서 확인할 수 있고, 오류 제보와 개선 의견도 GitHub 이슈로 받고 있습니다.
